# Syllabus Mapping

This assignment is designed around the three syllabus units supplied for Python Programming.

## UNIT I: Computational Thinking and Python Fundamentals
- Computational thinking and problem-solving methodology: all ten case studies.
- Algorithms, flowcharts and pseudocode: included in each case-study document.
- Python syntax, variables, data types, input/output and type conversion: all programs.
- Arithmetic, relational, logical and assignment operators: used across calculations and validation.
- Membership testing: used in transaction, festival and smart-campus tasks.
- Expressions, operator precedence and coding standards: practised throughout the programs.

## UNIT II: Control Structures, Strings and Functions
- Decision-making: if, if-else, nested conditions and elif.
- Iteration: for and while loops; continue is used to skip invalid records.
- Strings and methods: strip, upper and title are used in the programs.
- String formatting and pattern generation: formatted display and repeated separators are covered in the project materials.
- Functions: reusable functions are an additional practice area for these case studies.

## UNIT III: Lists, Tuples, Sets and Functions
- Lists and traversal/updating: applicant, product, student and registration records.
- Nested lists: student marks matrix and campus student records.
- Tuples and unpacking: timetable, transaction, scholarship and internship records.
- Sets and membership testing: festival registrations and campus event registrations.
- Functions: can be used to extract reusable validation and calculation logic.

## Note
The ten Python programs use built-in Python features and do not require external packages. The exact constructs used by each program are described in its case-study document.
