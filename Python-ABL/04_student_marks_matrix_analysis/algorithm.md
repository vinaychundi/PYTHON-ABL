# Algorithm: Student Marks Matrix Analysis

1. Start.
2. Read the number of students and number of subjects.
3. Read and store all subject names.
4. Create lists to store student names and marks.
5. For each student:
   - Read the student's name.
   - Create a row for that student's marks.
   - Read marks for every subject.
   - If a mark is below 0 or above 100, display an error and replace it with 0.
   - Add the completed row to the marks matrix.
6. For each student, calculate the total marks by adding the row values.
7. Calculate and display each student's average as total divided by number of subjects.
8. If at least one student exists, find and display the student with the highest total.
9. For each subject, calculate the average across all students and display it.
10. If a subject average is below 50, display a low-average warning.
11. Stop.
